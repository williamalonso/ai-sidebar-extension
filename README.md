### 🤔 Sobre o Projeto

A AI Sidebar Extension é uma extensão para navegador que adiciona uma barra lateral inteligente, permitindo interações rápidas com IA e automações diretamente em páginas web. O objetivo é facilitar o acesso a recursos de IA sem sair do fluxo de navegação.

---

### 🚀 Tecnologias

Este projeto utiliza as seguintes tecnologias:

- [JavaScript](https://developer.mozilla.org/pt-BR/docs/Web/JavaScript)
- [Chrome Extensions API](https://developer.chrome.com/docs/extensions/reference/api?hl=pt-br)
- [HTML5 & CSS3](https://developer.mozilla.org/pt-BR/docs/Web)

## 🙅 Instalação e Uso

Pré-requisitos

- Navegador Google Chrome (ou compatível)

1. Clone o repositório:

```bash
# Clone o repositório
git clone git@github.com:usuario/ai-sidebar-extension.git
```

Entre na pasta do projeto:
```bash
cd ai-sidebar-extension
```

2. Instale dependências (se houver):

```bash
# Caso utilize npm ou yarn
npm install
```

3. Configure variáveis de ambiente (se necessário):

```env
PANTRY_URL='sua_url_aqui'
```

4. Instale a extensão no Chrome:

- Abra o Chrome e acesse chrome://extensions
- Ative o Modo do Desenvolvedor
- Clique em "Carregar sem compactação" e selecione a pasta `ai-sidebar-extension` (a pasta raiz do repositório, que contém o arquivo `manifest.json`)
- Pronto! A barra lateral estará disponível nas páginas suportadas
