### 🤔 About

AI Sidebar Extension is a browser extension that adds an intelligent sidebar, enabling quick AI interactions and automations directly on web pages — without leaving your browsing flow.

---

### 🚀 Technologies

- [JavaScript](https://developer.mozilla.org/en-US/docs/Web/JavaScript)
- [Chrome Extensions API](https://developer.chrome.com/docs/extensions/reference/api)
- [HTML5 & CSS3](https://developer.mozilla.org/en-US/docs/Web)

---

## 🙅 Installation

**Prerequisites**

- Google Chrome (or compatible browser)

1. Clone the repository:

```bash
git clone git@github.com:usuario/ai-sidebar-extension.git
cd ai-sidebar-extension
```

2. Load the extension in Chrome:

- Open Chrome and go to `chrome://extensions`
- Enable **Developer mode** (toggle in the top-right corner)
- Click **"Load unpacked"** and select the `ai-sidebar-extension` folder (the root folder containing `manifest.json`)
- Done — the sidebar will be available on supported pages
